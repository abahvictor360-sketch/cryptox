# Project skills

Claude Code skills for building websites. Claude Code loads skills from `.claude/skills/` automatically.

| Skill | Upstream | License |
|---|---|---|
| react-three-fiber | pmndrs/react-three-fiber | MIT |
| liquid-glass-js | dashersw/liquid-glass-js | MIT |
| scroll-world | oso95/scroll-world | MIT |
| liquid-metal-logo | paper-design/liquid-logo | PolyForm Shield 1.0.0 |
| liquid-logo-plasma | collidingScopes/liquid-logo | MIT |
| shadergradient | ruucm/shadergradient | MIT |

To install them for **every** project on your own machine, copy them to your user skills directory:

```bash
mkdir -p ~/.claude/skills && cp -r .claude/skills/*/ ~/.claude/skills/
```
